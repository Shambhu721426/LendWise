LENDWISE DATASET

This folder contains the dataset required for training
the Loan Approval Prediction System.

Dataset Name:
Loan Prediction Problem Dataset

Source:
Kaggle

Dataset Link:
https://www.kaggle.com/datasets/altruistdelhite04/loan-prediction-problem-dataset

Instructions:

1. Download the dataset from Kaggle.
2. Extract the downloaded ZIP file.
3. Find the train.csv file.
4. Copy train.csv into this data folder.

Required file:

data/train.csv

The train.csv file must contain the Loan_Status target column.

Do not rename the target column.
